# Загрузка сайта, визитки и бота на reg.ru

Два архива:
- **site-update.zip** — обновление сайта: исправленная ссылка MAX, часы работы в разметке для поиска, визитка `/card/` и Mini App `/card/app/`, форма заявок с отправкой в Telegram, файл настроек `.htaccess`.
- **telegram-bot.zip** — бот. Токена в нём нет, вы введёте его сами на шаге 6.

Займёт 30–40 минут. Если что-то выглядит не так, как написано, остановитесь и пришлите скриншот.

## Шаг 1. Резервная копия сайта

1. reg.ru → «Услуги» → хостинг → «Панель управления» (откроется ISPmanager).
2. Слева «Менеджер файлов» → откройте папку `www`.
3. Выделите папку `realtyminaev.ru` → вверху «Архивировать» → формат zip → «Ok».
4. Выделите появившийся архив → «Скачать». Сохраните на компьютер.

## Шаг 2. Включить PHP для сайта

Без этого форма заявок на сайте не работает.

1. Слева «Сайты» → дважды нажмите на `realtyminaev.ru`.
2. В поле «Обработчик» выберите **PHP**, режим — **«CGI»** или **«модуль Apache»**, версия — самая новая 8.x.
3. В разделе SSL поставьте галочку **«Перенаправлять HTTP-запросы в HTTPS»**.
4. «Ok».
5. Пришлите мне скриншот формы перед нажатием «Ok» — сверю поля.

## Шаг 3. Создать сайт для бота

1. «Сайты» → «Создать сайт».
2. Имя: `bot.realtyminaev.ru`.
3. «Обработчик»: если в списке есть **Python** — пришлите скриншот полей, которые появятся, и подождите моего ответа. Если Python нет — выберите **PHP** (режим «модуль Apache» или «CGI»).
4. Включите **«Защищённое соединение (SSL)»** → сертификат **Let's Encrypt** → галочка «Перенаправлять HTTP-запросы в HTTPS».
5. «Ok». Через 5–15 минут откройте https://bot.realtyminaev.ru — страница должна открыться без предупреждения о безопасности (пустая или с ошибкой 403/404 — это нормально).

## Шаг 4. Загрузить обновление сайта

1. «Менеджер файлов» → `www` → `realtyminaev.ru`.
2. Вверху «Закачать» → выберите `site-update.zip` → «Ok».
3. Выделите `site-update.zip` → «Извлечь» → в текущую папку, **с заменой файлов** → «Ok».
4. Удалите `site-update.zip`.
5. Откройте в браузере https://realtyminaev.ru и https://realtyminaev.ru/card/ — обе страницы должны открыться.

## Шаг 5. Загрузить бота

1. «Менеджер файлов» → нажмите на самый верхний уровень (папку, где лежит `www`).
2. «Закачать» → `telegram-bot.zip` → «Ok».
3. Выделите архив → «Извлечь» → в текущую папку → «Ok». Появится папка `telegram-bot`.
4. Удалите `telegram-bot.zip`.

## Шаг 6. Установка бота одной командой

1. Слева «Shell-клиент» (может называться «Терминал»).
2. Скопируйте и вставьте команду, нажмите Enter:

       bash ~/telegram-bot/deploy/setup.sh

3. Скрипт проверит хостинг по шагам и спросит:
   - **токен бота** — вставьте из @BotFather (символы не отображаются, это нормально) и нажмите Enter;
   - **chat_id** — `326550369`;
   - **«Подключить бота к Telegram?»** — напишите `да`. С этого момента бот работает для клиентов.
4. Пришлите скриншот окна целиком — и при успехе, и при ошибке.

## Шаг 7. Проверка

1. Telegram → @RealtyMinaev_bot → «Старт»: приветствие и меню.
2. Кнопка «Визитка» внизу чата и в меню — открывается визитка.
3. Пройдите заявку до конца — она придёт вам в Telegram.
4. На сайте отправьте форму «Перезвоните мне» со своим номером — заявка придёт в Telegram и на minaevdmitry@gmail.com.
5. Яндекс Вебмастер → «Индексирование» → «Переобход страниц» → вставьте https://realtyminaev.ru/ и страницы услуг.

## Если бот перестал отвечать

Shell-клиент:

    cd ~/telegram-bot && python3 manage.py check

Перезапуск:

    touch ~/www/bot.realtyminaev.ru/tmp/restart.txt
