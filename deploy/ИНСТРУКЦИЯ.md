# Запуск: сайт, визитка, бот и автоответ в личных сообщениях

## Что загружаем и куда

| Файл | Что внутри | Куда на хостинге |
|---|---|---|
| `site-update.zip` | Обновлённые страницы сайта (ссылка MAX, разметка для поиска, новая политика и согласие), визитка `card/`, форма заявок `lead.php`, настройки `.htaccess` | В папку сайта: `www/realtyminaev.ru` |
| `telegram-bot.zip` | Бот, скрипт установки. Токена внутри нет | В домашнюю папку (там, где лежит папка `www`) |

Оба файла — в сообщении от разработчика. Скачайте их на компьютер, **не распаковывая**.

Где что окажется после установки:

```
домашняя папка
├── telegram-bot/            ← бот (из telegram-bot.zip), из интернета не открывается
└── www/
    ├── lead-config.php      ← создаст скрипт установки (токен для формы сайта)
    ├── realtyminaev.ru/     ← сайт (сюда — site-update.zip)
    │   └── card/            ← визитка и мини-приложение
    └── bot.realtyminaev.ru/ ← адрес бота (создадите на шаге 3, файлы запишет скрипт)
```

Время: 40–60 минут. Если что-то выглядит не так, как написано, — остановитесь и пришлите скриншот.

---

## Шаг 1. Резервная копия сайта (5 минут)

1. Откройте reg.ru → «Личный кабинет» → «Услуги» → «Хостинг Host-0» → кнопка «Панель управления». Откроется ISPmanager.
2. В меню слева нажмите «Менеджер файлов».
3. Откройте папку `www` (двойной щелчок).
4. Нажмите **один раз** на папку `realtyminaev.ru`, чтобы выделить её.
5. Вверху нажмите «Архивировать». Тип архива — **zip**, имя — `backup-sayt`. Нажмите «Ok».
6. Выделите появившийся `backup-sayt.zip` → вверху «Скачать». Сохраните на компьютер.

Проверка: файл `backup-sayt.zip` лежит у вас на компьютере, размер — несколько мегабайт.

## Шаг 2. Включить PHP для сайта (3 минуты)

Без этого не работает форма заявок на сайте.

1. Меню слева → «Сайты».
2. Дважды щёлкните по строке `realtyminaev.ru`.
3. Найдите поле «Обработчик» (или «PHP») и выберите **PHP**. Режим — «CGI» или «Модуль Apache», версия — самая новая 8.x.
4. В блоке «Защищённое соединение (SSL)» поставьте галочку «Перенаправлять HTTP-запросы в HTTPS».
5. **Перед «Ok» пришлите скриншот формы** — сверю поля. Затем «Ok».

Проверка: откройте https://realtyminaev.ru/lead.php — должна показаться короткая надпись «Не получилось отправить…», а не текст программы.

## Шаг 3. Создать адрес для бота (5 минут + до 15 минут ожидания)

1. «Сайты» → вверху «Создать сайт».
2. «Имя»: `bot.realtyminaev.ru`.
3. «Обработчик»: если в списке есть **Python** — пришлите скриншот полей, которые появятся, и дождитесь ответа. Если Python нет — выберите **PHP**, режим «CGI» или «Модуль Apache».
4. Включите «Защищённое соединение (SSL)» → сертификат **Let's Encrypt** → галочка «Перенаправлять HTTP-запросы в HTTPS».
5. «Ok».
6. Через 5–15 минут откройте https://bot.realtyminaev.ru. Пустая страница или ошибка 403/404 — нормально. Предупреждение браузера «Подключение не защищено» — не нормально: подождите ещё 15 минут или пришлите скриншот.

## Шаг 4. Загрузить сайт (5 минут)

1. «Менеджер файлов» → `www` → `realtyminaev.ru` (зайдите внутрь папки).
2. Вверху «Закачать» → «Выбрать файл» → `site-update.zip` → «Ok». Дождитесь окончания.
3. Выделите `site-update.zip` → вверху «Извлечь».
4. Папка назначения — текущая (`realtyminaev.ru`). Если есть вопрос о замене файлов — **«Заменить»** / «Да для всех». «Ok».
5. Выделите `site-update.zip` → «Удалить».

Проверка в браузере:
- https://realtyminaev.ru — сайт открывается как раньше;
- https://realtyminaev.ru/card/ — визитка;
- https://realtyminaev.ru/card/app/ — визитка для Telegram;
- https://realtyminaev.ru/politika-konfidencialnosti/ — вверху «ред. от 13 октября 2026».

## Шаг 5. Загрузить бота (3 минуты)

1. «Менеджер файлов» → вернитесь на самый верх (в домашнюю папку, где видна папка `www`).
2. «Закачать» → `telegram-bot.zip` → «Ok».
3. Выделите `telegram-bot.zip` → «Извлечь» → текущая папка → «Ok».
4. Удалите `telegram-bot.zip`.

Проверка: рядом с `www` появилась папка `telegram-bot`.

## Шаг 6. Включить режим Business у бота (2 минуты, в Telegram)

Нужно, чтобы бот мог отвечать в ваших личных сообщениях.

1. Откройте @BotFather → `/mybots` → `@RealtyMinaev_bot`.
2. «Bot Settings» → «Business Mode» → «Turn on».

## Шаг 7. Установка бота одной командой (5 минут)

1. ISPmanager → меню слева «Shell-клиент» (может называться «Терминал»).
2. Скопируйте команду, вставьте в окно и нажмите Enter:

       bash ~/telegram-bot/deploy/setup.sh

3. Скрипт проверит хостинг по шагам (зелёные галочки) и спросит:
   - **токен** — скопируйте в @BotFather (`/mybots` → бот → «API Token»), вставьте, Enter. Символы не отображаются — так и должно быть;
   - **chat_id** — число из @userinfobot (оно есть в переписке с разработчиком), Enter;
   - **«Подключить бота к Telegram и включить кнопку «Визитка»?»** — напишите `да`, Enter. С этого момента бот работает для клиентов.
4. Пришлите скриншот окна целиком — и при успехе, и при ошибке.

## Шаг 8. Меню бота в ваших личных сообщениях (3 минуты, в Telegram)

Когда новый человек (не из ваших контактов) впервые пишет вам в @RealtyMinaev, бот один раз отвечает от вашего имени: «Спасибо за сообщение — отвечу лично…» и кнопки «Услуги и частые вопросы», «Оставить заявку», «Визитка». Дальше вы переписываетесь сами. Если вы написали человеку первым, автоответа не будет.

1. Telegram → «Настройки» → «Telegram для бизнеса» → «Чат-боты».
2. Введите `@RealtyMinaev_bot` и выберите его.
3. «Доступ к чатам»: **«Все личные чаты, кроме…»** → в исключения добавьте **«Контакты»**.
4. Права бота: включите **«Отвечать на сообщения»**. Остальные права (удалять, управлять) — выключены.
5. Сохраните.

## Шаг 9. Проверка всей связки (10 минут)

1. @RealtyMinaev_bot → «Старт»: приветствие и меню.
2. Кнопка «Визитка» в меню и синяя кнопка слева от поля ввода — открывают визитку.
3. Пройдите заявку до конца — сообщение «Новая заявка из Telegram-бота» придёт вам.
4. На сайте отправьте форму «Перезвоните мне» со своим номером — заявка придёт в Telegram и на minaevdmitry@gmail.com.
5. Попросите знакомого, которого **нет** в ваших контактах, написать вам в Telegram — он получит автоответ с кнопками.
6. Яндекс Вебмастер → «Индексирование» → «Переобход страниц» → вставьте https://realtyminaev.ru/ и страницы услуг.

## Обязанности по персональным данным (вне сайта)

Нужны до запуска бота и формы с отправкой в Telegram. Тексты политики и согласия перед публикацией покажите юристу.

1. Проверьте, есть ли ваше ИП в реестре операторов: pd.rkn.gov.ru → «Реестр операторов» → поиск по ИНН 772327416300. Если нет — подайте уведомление об обработке персональных данных (Госуслуги или pd.rkn.gov.ru).
2. Подайте уведомление о трансграничной передаче (Telegram, Google) — до начала передачи, отдельно от уведомления из пункта 1.

## Если бот перестал отвечать

Shell-клиент:

    cd ~/telegram-bot && python3 manage.py check

Перезапуск:

    touch ~/www/bot.realtyminaev.ru/tmp/restart.txt
