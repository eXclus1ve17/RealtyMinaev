# Выкладка сайта на reg.ru

Архив: `realtyminaev-sajt-ГГГГ-ММ-ДД.zip` — содержимое папки `_site` после `npx eleventy`.
В архиве 112 файлов, включая скрытый `.htaccess`.

## 1. Резервная копия (5 минут)

1. Панель reg.ru → «Хостинг» → «Менеджер файлов» (или ISPmanager → «Файлы»).
2. Откройте папку сайта: `www/realtyminaev.ru`.
3. Выделите всё содержимое → «Архивировать» → назовите `backup-ДАТА.zip`.
4. Скачайте архив себе. Это откат, если что-то пойдёт не так.

## 2. Загрузка

1. В той же папке `www/realtyminaev.ru` нажмите «Загрузить» и выберите архив сайта.
2. На загруженном архиве: «Извлечь» → в текущую папку, **с заменой файлов**.
3. Включите показ скрытых файлов и убедитесь, что в папке есть `.htaccess`.
4. Удалите загруженный zip из папки сайта.

Папка `forma-96` в архиве совпадает с той, что сейчас на сайте, — её можно перезаписать.

## 3. PHP и заявки

1. Панель хостинга → «Настройки PHP»: версия 8.1 или новее.
2. Откройте любую страницу услуги, отправьте тестовую заявку (имя «Тест», ваш телефон).
3. Должно появиться «Спасибо», а письмо — прийти на d.m.minaev@landis-estate.com.
4. Журнал заявок создаётся автоматически **вне** папки сайта: `www/leads/leads.csv`.
   Наружу он не отдаётся. Записи старше года удаляются сами.
5. Если письма нет — проверьте «Спам» и добавьте `no-reply@realtyminaev.ru` в контакты.
   Заявка при этом всё равно сохранена в журнале.

## 4. SPF — чтобы письма не уходили в спам

Панель reg.ru → «Домены» → realtyminaev.ru → «DNS-серверы и управление зоной» → «Добавить запись» → TXT:

- Имя: `@`
- Значение: `v=spf1 a mx include:_spf.hosting.reg.ru ~all`

Если TXT-запись с `v=spf1` уже есть, не создавайте вторую — допишите `include:_spf.hosting.reg.ru` в существующую.
Изменение вступает в силу до 24 часов.

## 5. Проверка после выкладки

- https://realtyminaev.ru/ — главная открывается, Forma 96 работает.
- http://realtyminaev.ru и https://www.realtyminaev.ru — перенаправляют на https://realtyminaev.ru/.
- https://realtyminaev.ru/index.html — перенаправляет на `/`.
- https://realtyminaev.ru/nesushestvuyushaya/ — открывается своя страница 404.
- На телефоне: нижняя панель «Позвонить / Telegram / WhatsApp / MAX».
- Баннер cookie: после «Согласен» Метрика начинает считать визиты.

## 6. Яндекс Вебмастер

1. «Индексирование» → «Файлы Sitemap» → добавить `https://realtyminaev.ru/sitemap.xml`.
2. «Индексирование» → «Переобход страниц» → вставить адреса из sitemap (до 20 в день).
3. «Информация о сайте» → «Регион» → Москва.

## 7. Google Search Console

1. https://search.google.com/search-console → «Добавить ресурс» → «Префикс URL» → `https://realtyminaev.ru/`.
2. Способ подтверждения «HTML-тег» → скопировать строку `<meta name="google-site-verification" content="…">` и прислать.
3. После добавления тега в сайт — «Подтвердить», затем «Файлы Sitemap» → `sitemap.xml`.

## 8. Цели в Метрике

Метрика → «Цели» → «Добавить цель» → «JavaScript-событие», идентификаторы:

| Идентификатор | Что считает |
|---|---|
| `call` | Нажатие на телефон |
| `write_telegram` | «Написать» / Telegram |
| `write_whatsapp` | WhatsApp |
| `write_max` | MAX |
| `lead_form` | Отправленная заявка |
| `rgr_registry` | Проверка аттестата в реестре РГР |
| `tg_subscribe` | Подписка на канал из статьи |

## Откат

Удалите файлы сайта и распакуйте `backup-ДАТА.zip` из шага 1.
