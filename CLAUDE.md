# Сайт realtyminaev.ru

Сайт брокера Дмитрия Минаева. Eleventy: `src/` → `_site/`, сборка `npx eleventy`.
Хостинг reg.ru, папка `~/www/realtyminaev.ru`. Подробности — `docs/vykladka-na-hosting.md`.

## Правила работы

- Ничего не менять и не выкладывать без одобрения Дмитрия. Факты не выдумывать.
- Отвечать по-русски, кратко. Вопросы — блоком по 3–4, с вариантами и рекомендацией.
- Тексты и разметку делать в пользу высокой выдачи в Яндексе и Google.

## Выкладка — всегда кодом для Shell-клиента

После каждой одобренной правки:

1. Закоммитить исходники и запустить `scripts/publish-site.sh` — он собирает сайт и обновляет ветку `site` на GitHub.
2. Прислать Дмитрию готовую команду для Shell-клиента reg.ru (одна строка, без комментариев `#`):

```
curl -sL https://github.com/eXclus1ve17/RealtyMinaev/archive/refs/heads/site.tar.gz | tar xz --strip-components=1 -C ~/www/realtyminaev.ru
```

Если нужны другие действия на сервере — тоже давать готовыми командами, по одной, без комментариев.
