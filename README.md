# RealtyMinaev

Сайт брокера по недвижимости Дмитрия Минаева — https://realtyminaev.ru

- `index.html` — главная (правится вручную)
- `_build/` — сборка внутренних страниц: тексты в `_build/pages.py`, запуск `python3 _build/build.py`
- `consent.js` — cookie-согласие, Яндекс.Метрика и цели
- `lead.js` + `send.php` — форма заявки (Telegram + почта)
- Выкладка на хостинг и настройка формы — в [DEPLOY.md](DEPLOY.md)
