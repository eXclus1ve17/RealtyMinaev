# Telegram-бот @RealtyMinaev_bot

Бот отвечает на частые вопросы по кнопкам, открывает визитку, принимает заявки и пересылает их Дмитрию в Telegram. Заявки в боте не хранятся: незаконченный черновик удаляется после отправки, отмены или через сутки.

## Как поправить текст

1. Откройте `content.yaml` в любом текстовом редакторе (на Mac — TextEdit в режиме «Простой текст», удобнее — VS Code).
2. Найдите нужный текст по словам из него и поправьте. Отступы в начале строк не трогайте, используйте пробелы, а не Tab.
3. Жирный шрифт — `<b>текст</b>`, ссылка — `<a href="https://…">текст</a>`. Символ `<` без тега писать нельзя.
4. Проверьте файл: в Терминале, в папке `telegram-bot`, выполните `python3 check_content.py`. Должно быть «Всё в порядке».
5. Загрузите `content.yaml` на хостинг и перезапустите бота (см. ниже).

Ответ в «Частых вопросах» — не длиннее 600 знаков. Если вопрос длинный, добавьте строку `button:` с коротким текстом для кнопки.

## Как перезапустить бота

В ISPmanager → «Shell-клиент» выполните:

    touch ~/www/bot.realtyminaev.ru/tmp/restart.txt

Новые тексты из `content.yaml` подхватываются после перезапуска.

## Если бот не отвечает

1. Откройте https://bot.realtyminaev.ru/health — должно быть `ok`. Если нет — перезапустите бота.
2. В Shell-клиенте: `cd ~/telegram-bot && python3 manage.py check` — покажет связь с Telegram, состояние вебхука и последнюю ошибку доставки.
3. Посмотрите файл `data/errors.log` на хостинге: там только технические ошибки, без данных клиентов.
4. Если после правки текстов — запустите `python3 check_content.py`, он покажет ошибку и место.
5. Если ничего не помогло — верните прошлую версию `content.yaml` и перезапустите.

## Устройство

- `content.yaml` — все тексты и кнопки.
- `bot/handlers.py` — порядок шагов: меню, услуги, вопросы, заявка.
- `bot/app.py` — приём обновлений от Telegram (вебхук с проверкой секретного токена).
- `.env` — токен, chat_id и секрет вебхука. Создаётся из `.env.example` только на хостинге, никому не пересылается и не попадает в репозиторий.
- `manage.py` — проверка (`check`), вебхук (`set-webhook`, `delete-webhook`), кнопка «Визитка» и команды (`setup-menu`).
- `deploy/setup.sh` — установка на reg.ru одной командой.
- `vendor/` — встроенная копия PyYAML, чтобы не ставить пакеты на хостинге.
- `run_polling.py` — запуск на своём компьютере для проверки; не запускается, если бот уже работает на хостинге.
- Тесты: `python3 -m unittest discover -s tests`.

Папку бота нельзя класть внутрь папки сайта (`public_html`): файлы бота и `.env` не должны открываться из интернета.
